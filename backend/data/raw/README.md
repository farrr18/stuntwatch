# Raw data inputs

Keep source CSV files in this directory and do not commit datasets that are not
licensed for redistribution. The pipeline expects:

| File | How it is obtained |
| --- | --- |
| `stuntwatch_bps_kab_v2.csv` | Generated by `python -m stuntwatch.data.pipeline` using `BPS_API_KEY`. |
| `dataset_risiko_stunting_kabkota.csv` | The district-level target dataset used by the project; must include `kabupaten_kota`, `provinsi`, `stunting_pct`, and `kategori_prevalensi_stunting`. Obtain it from the project's authorized source. |
| `wash_v2_long.csv` | The WASH export in long format; must include `domain`, `kode`, `label`, `value`, `year`, `turvar`, `concept`, and `var_id`. Obtain it from the project's authorized source. |
| `hdx/idn_adm2_facilities.csv` | HeiGIT HDX ADM2 facilities data. |
| `hdx/idn_adm2_demographics.csv` | HeiGIT HDX ADM2 demographics data. |
| `hdx/idn_adm2_rural_population.csv` | HeiGIT HDX ADM2 rural-population data. |
| `hdx/idn_adm2_rai.csv` | HeiGIT HDX ADM2 Rural Access Index data. |

The four HDX CSVs are present in the repository's `hdx/` subdirectory. The
target and WASH files are intentionally not included. Do not substitute
similarly named files without checking their columns and year coverage.
